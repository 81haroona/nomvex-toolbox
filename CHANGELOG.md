# Changelog

## 0.2.0 — 2026-10-21

- Add a continuously refreshed open-source tools and agents registry.
- Discover repositories from curated agent/MCP lists plus NOMVEX core seeds.
- Fail closed on missing, ambiguous, archived, forked, or non-allowlisted license metadata.
- Keep indexed projects reference-only until separately tested.
- Add combined catalog search, source/metadata provenance, quarantine output, parser tests, and a scheduled data-only refresh PR.
- Preserve Web Checks and its cross-platform verification as the first original NOMVEX utility.


## 0.1.2 — 2026-10-21

- Make the public GitHub presentation and primary documentation English-first.
- Keep localized report output as a product capability rather than repository presentation language.
- Expand GitHub-hosted verification to Ubuntu, Windows, and macOS on Node 22 and 24.
- Add healthy-demo and deliberately-broken-demo verification to hosted CI.
- Add package discovery metadata and English-only issue templates.
- Generalize POSIX symlink regression coverage and explicitly report platform-specific skips.

## 0.1.1 — 2026-10-21

- Reuse the existing NOMVEX platform mark in the repository and localized HTML reports.
- Embed the exact logo bytes for offline reports while preserving restrictive report content policy.
- Refresh sample reports, responsive visual evidence, and release packaging.

## 0.1.0 — 2026-10-21

- Original Web Checks CLI and JavaScript library for redirects, language persistence, and PDF/JSON/CSV/text downloads.
- Strict declarative configuration, bounded concurrency, exact HTTP(S) origin guard, and temporary-file cleanup.
- Localized HTML/JSON reports with explicit pass/fail/error/skipped states.
- Synthetic healthy and intentionally broken journeys.
- Source-reviewed catalog of 24 tools, contribution/security policies, and Apache-2.0 project license.
- Isolated GitHub-hosted CI with pinned Actions and read-only repository permissions.

See [verification evidence](docs/ACCEPTANCE.md) for what actually ran and what remains unverified.
